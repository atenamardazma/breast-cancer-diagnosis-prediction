# Breast Cancer Diagnosis Prediction Using Machine Learning

## Project Overview

This project applies supervised machine learning techniques to classify breast tumors as benign or malignant using the Breast Cancer Wisconsin Diagnostic Dataset.

The objective is to explore diagnostic features, build classification models, evaluate their predictive performance, and identify features associated with tumor classification.

**This project is intended for educational and portfolio purposes only, not for clinical diagnosis.**

## Dataset

**Source:** Breast Cancer Wisconsin Diagnostic Dataset (UCI Machine Learning Repository)

The dataset contains:

- 569 observations
- 30 numerical features
- Two target classes: Malignant and Benign

Features describe characteristics of cell nuclei, including radius, texture, perimeter, area, smoothness, and concavity.

## Key Findings

The analysis demonstrates how supervised machine learning can identify patterns in diagnostic measurements and distinguish between benign and malignant tumors.

Model evaluation provides insights into classification performance and the importance of considering false negatives in medical classification tasks.

## Limitations

- The dataset is relatively small.
- Results have not been externally validated on independent clinical populations.
- Predictive relationships do not establish causation.
- Model performance cannot be generalized to real-world patient care without further validation.

## Conclusion

This project demonstrates practical skills in data preprocessing, exploratory data analysis, supervised machine learning, model evaluation, and interpretation.

It also highlights the importance of responsible model development when working with healthcare-related data.
